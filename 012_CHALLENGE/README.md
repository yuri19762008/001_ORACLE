# 📊 Análisis de Evasión de Clientes - TelecomX

## 📖 Descripción  
Este proyecto analiza la evasión (*Churn*) de clientes en TelecomX mediante visualizaciones y análisis de datos. Se exploran patrones en variables como género, tipo de contrato, método de pago y cargos mensuales para comprender los factores que influyen en la cancelación del servicio.

## 🚀 Instalación  
Para ejecutar este proyecto, asegúrate de tener **Python 3.8+** y las siguientes dependencias instaladas:  

```bash
pip install pandas seaborn matplotlib
